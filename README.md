# nia-web

Public static site for NIA -> **niapower.org** via GitHub Pages (ADR-020 Phase 4).

**PUBLIC repo.** Zero finance data, zero PII, no `_system`. Marketing / public content only.
Anything sensitive belongs in the private `nia` repo, never here.

Deploy: GitHub -> Settings -> Pages -> Deploy from branch (main / root). Then point the
`niapower.org` DNS at GitHub Pages and set the custom domain in Pages settings.
