# Fonts

- **Anton** (headings): SIL Open Font License 1.1, see `anton/OFL.txt`.
- **Inter** (body, buttons): SIL Open Font License 1.1, https://github.com/rsms/inter/blob/master/LICENSE.txt
  Only the weights the site uses are here (400, 500, 600, 700).

Both match the Squarespace theme (headings Anton; paragraphs, buttons and misc Inter).
The uploaded Doyle and Swiss 721 fonts are commercial and were never used on the site, so they are
not carried over.
